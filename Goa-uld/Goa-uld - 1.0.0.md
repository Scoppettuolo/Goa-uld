## 1. INTRODUCCIÓN Y FILOSOFÍA DEL PROYECTO

### 1.1 ¿Qué es esto?

Este documento es la reconstrucción sistemática del **idioma Goa'uld** de la franquicia *Stargate*, convertido en una lengua artificial (conlang) funcional, coherente y aprendible.

### 1.2 ¿Por qué?

En la serie original, el Goa'uld es lo que se conoce como *gibberish*: palabras inventadas sobre la marcha sin gramática real. El caso más famoso es **"Kree"**, que significa "atención", "fuego", "muévanse", "mírenme" o "arrodíllense" según el capítulo.

Este proyecto resuelve ese problema de raíz mediante tres innovaciones:

1. **Sistema tonal:** *Kree* cambia de significado según su tono.
2. **Morfología aglutinante:** Las palabras se descomponen en morfemas analizables.
3. **Pragmática de registros:** El tono marca jerarquía social (dios, Jaffa, esclavo, Tau'ri).

### 1.3 Principios de diseño

- **Coherencia interna:** Toda palabra puede analizarse morfológicamente.
- **Transparencia:** El significado se deduce de las partes.
- **Productividad:** Cualquier concepto nuevo se forma con raíces existentes.
- **Respeto al canon:** Se conservan las palabras y frases icónicas.
- **Naturalidad:** Sigue patrones de lenguas reales (nobiin, chino, turco).

### 2.1 Consonantes

|---|---|---|---|---|---|---|
| Oclusivas | p, b | | t, d | | k, g | ʔ (’) |

| Africadas | | | | tʃ (ch), dʒ (j) | | |
| Aproximantes | | | l, r | | | |

**Notas:**
- El apóstrofo **’** = /ʔ/ (oclusiva glotal).
- *Sh* = /ʃ/, *ch* = /tʃ/, *j* = /dʒ/.
- *Kree* = /kriː/ con cluster /kr/ permitido.

### 2.2 Vocales

| Anterior | Central | Posterior |
|---|---|---|
| i | | u |
| e | | o |
| | a | |

**Diptongos:** ai, au, ei, oi, ui.  
Ejemplos: *Chappa’ai* (ai), *Tau’ri* (au), *Lo’taur* (au).

### 2.3 Estructura silábica

- Patrón básico: **(C)(C)V(C)**
- Onset: cualquier consonante simple, o cluster /kr/, /tr/, /ʃr/.
- Coda: cualquier consonante simple, o /ʔ/.
- El apóstrofo marca frontera de morfema y se pronuncia como /ʔ/.

### 2.4 Acento y tono

- Cada sílaba lleva **un tono**.
- El acento es tonal: la sílaba tónica recibe el tono principal.
- En palabras compuestas, cada morfema conserva su tono base (si hay apóstrofo).

## 3. SISTEMA TONAL

### 3.1 Inventario tonal

| Tono | Notación | Descripción | Ejemplo |
|---|---|---|---|
| Alto plano | ā | sostenido, agudo | krē |
| Bajo plano | à | sostenido, grave | krè |
| Ascendente | á | sube | kré |
| Descendente | â | baja | krê |
| Cóncavo | ǎ | baja y sube | krě |

### 3.2 Funciones de los tonos

| Nivel | Función | Ejemplo |
|---|---|---|
| **Léxico** | Distingue significados de raíces | ren (estrella) vs. rèn (morir) |
| **Gramatical** | Marca tiempo, modo, negación | nok (ahora) vs. nokia (antes) |
| **Pragmático** | Marca respeto, amenaza, sumisión | kree con 5 tonos |

### 3.3 Sandhi tonal

Se aplica **solo dentro de la palabra** y **solo cuando no hay apóstrofo**. El apóstrofo bloquea el sandhi.

**Reglas:**

1. **Nivelación de planos iguales**
   - ā + ā → á + ā
   - à + à → ǎ + à

2. **Contraste de planos**
   - à + ā → á + ā
   - ā + à → â + à

3. **Simplificación de contornos**
   - á + â → ā + à
   - â + á → à + ā

4. **Simplificación del cóncavo**
   - ǎ + X → à + X
   - X + ǎ → X + à

5. **Asimilación ante descendente**
   - à + â → á + â
   - â + à → à + à

### 3.4 Ejemplos de sandhi

| Palabra | Análisis | Resultado | Significado |
|---|---|---|---|
| Na’onak | na (â) + onak (ā) | nâ’onāk | no dios |
| Shol’va | shol (á) + -va (á) | shol’vá | traidor |
| Nokiak | nok (à) + -ia (â) + -k (à) | nókiàk | antes |
| Tau’ri | tau (à) + -ri (à) | tau’rì | los de la Tierra |

## 4. MORFOLOGÍA AGLUTINANTE

### 4.1 Plantilla de la palabra

> **(Partícula) + (Prefijos) + RAÍZ + (Sufijos) + (Partícula)**

- La **raíz** lleva el significado léxico y su tono base.
- Los **prefijos** son derivativos o de persona.
- Los **sufijos** se apilan en orden fijo.
- Las **partículas** pueden ir antes o después, y son clíticos.
- El **apóstrofo (’)** marca frontera de morfema y bloquea el sandhi.

### 4.2 Prefijos

| Prefijo | Tono | Función | Ejemplo |
|---|---|---|---|
| **na-** | â | negación / privativo | na’onak = no dios |
| **ha-** | à | locativo / posesivo | ha’tak = nave |
| **mel-** | à | temporal / direccional | mel nok = más tarde |
| **kree-** | à | imperativo / vocativo | kree hol = ¡vamos! |
| **ta-** | à | 1ª persona | ta’jaffa = yo, tu sirviente |
| **lo-** | à | 2ª persona | lo’taur = tu sirviente |

### 4.3 Sufijos (orden fijo)

| Posición | Sufijo | Tono | Función |
|---|---|---|---|
| 1 | **-ia** | â | negación |
| 2 | **-k** | à | copulativo (ser/estar) |
| 3 | **-va** | á | agente |
| 4 | **-rak** | á | agente / oficio |
| 5 | **-ta** | ā | ritual / sagrado |
| 6 | **-ri** | à | gentilicio |
| 7 | **-p** | ā | plural |

**Regla:** Un sufijo no puede aparecer dos veces en la misma palabra.

### 4.4 Clases de raíces

| Clase | Descripción | Ejemplo | Comportamiento |
|---|---|---|---|
| **Nominal** | Sustantivos | onak, jaffa, tau | Acepta -p, -ri, -ta |
| **Verbal** | Verbos | hol, mol, tak | Acepta -k, -va |
| **Adjetival** | Cualidades | shol, kek | Acepta -va, -rak |
| **Partícula** | Función gramatical | kree, mel, sha | No acepta sufijos |

### 4.5 Derivación

| Derivación | Fórmula | Ejemplo |
|---|---|---|
| Agente | raíz + **-va** | shol → shol’va (traidor) |
| Oficio | raíz + **-rak** | ash → ash’rak (asesino) |
| Ritual | raíz + **-ta** | prim → prim’ta (ceremonia) |
| Gentilicio | raíz + **-ri** | tau → tau’ri (los de la Tierra) |
| Estado | raíz + **-k** | kek → kek’k (muerto) |
| Plural | raíz + **-p** | jaffa → jaffa-p (jaffas) |
| Negación | **na-** + raíz | na’onak (no dios) |
| Negación verbal | raíz + **-ia** | tak’ia (no es) |

## 5. SINTAXIS SOV

### 5.1 Principios sintácticos

1. **Orden básico: SOV** (Sujeto–Objeto–Verbo).
2. **Lengua de núcleo final (head-final).**
3. **Partículas al final de la frase o cláusula.**
4. **El verbo no se conjuga.**
5. **El apóstrofo no afecta la sintaxis.**

### 5.2 Oración simple

> **[Sujeto] + [Objeto] + [Verbo] + (Partículas)**

## 8. COMPOSICIÓN TRANSPARENTE

### 8.1 Principio

> **Toda palabra nueva se forma uniendo dos o más raíces existentes. El significado es la suma transparente de sus partes.**

### 8.2 Reglas

1. La raíz principal es la **segunda** (el núcleo).
2. La primera raíz **modifica** o **especifica**.
3. Se usa apóstrofo si hay frontera de morfema.
4. El tono se asigna según sandhi.

## 10. GUÍA DE USO RÁPIDO

### 10.1 Cómo construir una frase

1. **Identifica el sujeto** (ta, lo, on, o un sustantivo).
2. **Identifica el objeto** (sustantivo o pronombre).
3. **Identifica el verbo** (raíz verbal).
4. **Ordena:** Sujeto + Objeto + Verbo.
5. **Añade partículas** de tiempo, negación o pregunta.
6. **Ajusta el tono** según el registro (dios, Jaffa, esclavo, Tau’ri).

### 10.2 Ejemplo paso a paso

**Quiero decir:** "Yo mato al Jaffa ahora."

1. Sujeto: **ta** (yo)
2. Objeto: **jaffa**
3. Verbo: **mol** (matar)
4. Orden: **Ta jaffa mol.**
5. Partícula de tiempo: **nok** (ahora)
6. Resultado: **Ta jaffa mol nok.**

**Con tono de dios:** *Ta jaffa mol nōk.* (tono alto)  
**Con tono de esclavo:** *Ta jaffa mol nòk.* (tono bajo)

## APÉNDICE D: EJEMPLO DE DIÁLOGO COMPLETO

**Escena:** Apophis interroga a un Jaffa que ha fallado.

**Apophis (tono alto, autoritario):**
> **Jaffa, krē! Lo tak krê!**
> → ¡Jaffa, atención! ¡Habla!

**Jaffa (tono cóncavo, temeroso):**
> **Onak, ta na’tak ǎ. Tau’ri hol mel.**
> → Dios, yo no hablo (con dignidad). El Tau’ri fue después.

**Apophis (tono descendente, furioso):**
> **Shol’va! Lo ren krê!**
> → ¡Traidor! ¡Tú morirás!

**Jaffa (tono bajo, suplicante):**
> **Onak, ta jaffa’tyl ǎ. Quell shak.**
> → Dios, yo soy tu sirviente. Por favor.

**Apophis (tono cóncavo, amenazante):**
> **Na’onak! Lo shol’va tak krě!**
> → ¡No dios! ¡Tú eres traidor!
